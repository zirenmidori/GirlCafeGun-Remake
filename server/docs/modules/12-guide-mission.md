# 指引日程

## 当前完成度

**核心可用。** 15 条任务、5 档累计奖励、状态投影、领奖和持久化已经完成；15 条任务都有
服务端进度来源，第 5 档累计奖励（需 15 条）可以领取。

## 状态与领奖

- 任务组 5，任务进度位于 bit 1～31，bit 0 为已领奖；
- `41001` 的 bit 1～5 保存累计奖励领取状态；
- `41002` 是服务端专用的已开始特训类型位掩码（类型 n 占 bit n-1），客户端不读取；
- 登录时按当前 v1 业务状态单调投影进度，不覆盖领奖标记；
- `GuideMissionGetAward` 校验完成、未领取和前置任务已领取；
- `GuideProgressGetAward` 按完成任务数量校验 3/6/9/12/15；
- 奖励、任务值、背包、货币和少女变化在同一事务提交；
- 使用 `MissionMgrMsg nMission=3/4` 刷新客户端。

## 旧存档补偿

登录时按存档中仍可见的状态补记：

- 40026：已保存的助战编队 2001～2006 中有主卡；
- 40014：当前仍在进行的特训类型（已结束的特训不留痕迹）；
- 40018：喜好礼物秘闻已解锁，或约定任务 `GiftCount` 进度大于 0（普通礼物不留痕迹）。

无痕迹的旧操作从下一次特训或赠礼开始计入。
